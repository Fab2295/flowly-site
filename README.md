# Flowly — site

Site do app Flowly (iPhone e Apple Watch), publicado no GitHub Pages.

- `index.html` — página inicial com o copo 3D (`js/flowly-3d.js`, three.js 0.160 via CDN)
- `privacidade.html`, `suporte.html`, `termos.html` — páginas exigidas pela App Store

Sem build: é HTML/CSS/JS estático. Para ver local: `python3 -m http.server` e abrir `http://localhost:8000`.
